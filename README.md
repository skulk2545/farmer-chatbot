# Farmer Chatbot

## Overview
A conversational AI chatbot designed specifically for farmers, providing real-time agricultural insights, crop recommendations, weather integration, and market updates.

## Technologies
- Python
- TensorFlow
- Flask
- PostgreSQL
- React.js (Frontend)
- Docker
- Redis

## Features
- Natural Language Processing
- Real-time chat interface
- Integration with farming databases
- Machine Learning for predictive analytics
- Weather forecasting integration
- Crop disease detection
- Market price analysis
- Multi-language support

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set up environment variables in `.env`
4. Run the Flask server: `python app.py`

## Usage
Start the chatbot with:
```bash
python farmer_chatbot.py
```
